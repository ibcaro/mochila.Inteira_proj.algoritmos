# mochila.Inteira_proj.algoritmos

Escreva um programa em Linguagem C para o algoritmo da mochila inteira visto
em aula. Seu algoritmo deve simular exatamente o algoritmo visto em aula, ou seja,
não há repetição dos objetos e todos os objetos cabem na mochila. Você deve fornecer
também o algoritmo ingênuo para resolver o mesmo problema (o algoritmo ingênuo não
usa programação dinâmica, apenas combina todos os objetos contra todos e verifica
o subconjunto de máximo valor). Compare os dois algoritmos no número de passos.


1. A entrada se dará por meio de um arquivo in.txt fornecido pelos alunos que de-
screve uma tabela de até 100 objetos. O arquivo deve fornecer nome, peso e
valor de cada objeto, bem como a capacidade da mochila.

2. A saída do programa se dará na tela com os objetos escolhidos e a soma do valor
deles.
